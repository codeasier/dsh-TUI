### 交叉回归的适配

- stderr 销毁回归的无换行尾部、销毁前在途通知和销毁后迟到输入改为带 `Error:` 的合成行。否则补丁的 info 静默会让“未销毁仍报错”的负对照失效，也会令取消断言没有实际计时器可取消。保留真实子进程尾部、失效 Channel 与重复销毁的检查。
- mention-provider 回归用 composer controller 的精确草稿 `Camera ` 判断 Enter 接受结果，不依赖上游输入行以 `❯` 开头的外观；补丁保留黄色左条带。候选显示/异步选中/同批输入等其余上游断言保留。
- 同时保留 `verify-claude-sdk-status` 与 `verify-ime-cursor-repair`，以及 mention-provider、宿主迁移与原补丁的全部回归登记；不放宽门禁。
- 迁移文档同时保留宿主解析失败排查与 OpenCode 会话行计数说明，随包 guide 逐字节同步。

## 验证状态

本轮只做静态核对：来源与文件归属、冲突标记/空白、JS/TS/TSX 语法、shell 语法、JSON、上游独有文件与旧补丁独有文件的保真、版本/依赖契约、回归登记与 guide 镜像。**语法解析不是 TypeScript 类型检查，也不是运行验收。** 具体命令和结果见迁移 PR。

**未执行**：依赖安装、TypeScript 编译、`pnpm build` / `verify:build` / `verify:package` / `smoke`、各行为回归与完整 CI、真实终端、实际安装/升级、Windows 与设备验收。常规 UT/build 留给已有 CI；本轮不启用或重跑暂停的 Actions。未运行、空检查与 skipped 均不记为通过，也不以迁移完成表示可合并或可发布。

以后获准运行时，使用 Node 24（宿主至少 24.9）与 package 指定的 pnpm，编译一次、复用产物：

```sh
git submodule update --init --recursive
pnpm install --frozen-lockfile --ignore-scripts
pnpm compile
pnpm verify:build
pnpm verify:package
pnpm smoke
node scripts/run-ci-group.mjs render-scroll
node scripts/run-ci-group.mjs input-terminal
node scripts/run-ci-group.mjs session-workspace
node scripts/run-ci-group.mjs channel-ui
```

尤其关注 `verify-mention-providers.tsx`、`verify-child-stderr.tsx`、`verify-claude-sdk-status.tsx`、`verify-cli-subcommands.mjs`、`verify-backend-host.ts`、OpenCode 三组回归、jobs/cache、thinking hook、catalog 和安装回滚；核对最终 head 的 `ci-gate`、rc.3 `alpha-compat` 及适用平台检查。
