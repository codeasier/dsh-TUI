## 范围与基线

- 新基线：上游 v0.19.0，`224f847d02c2157f43862d2792cf9d7459222f4c`。
- 旧定制：v0.16.1 `73ff99fbed56563bf154d719effd09f9f9725349` 到 v0.16.1-patch `c619ba52260694aac6b8415f30e62608092f2f73` 的 12 个提交。
- 主验证线沿用上游 DSH **0.2.2-rc.1**，兼容范围保持上游清单；这不是对未验证的 0.2.2 稳定版的承诺。
- 按能力迁移而非整串 cherry-pick。旧设备部署记录及 package ID 留在旧分支历史，不证明新版已安装或验收。

迁移内容包括安装保护与 ag-search、jobs/provider/catalog 与 `/fast`、OpenCode 只读导入、stderr/sharp、主题与转录、悬挂缩进/inline 历史/IME、Unicode 编辑与原地多行 Launchpad、代码块与表格原文复制。

保留 v0.19.0 的首次启动登录和模型选择、官方 worktree、插件启停/卸载授权撤销、宿主卸载后结束会话与暂存输入、软折行/分栏复制和展开工具卡背景。原地多行 Launchpad 刻意替换“按换行进入 Chat”的交互；同批输入、图片原子删除和挂起后就绪再接收输入的保护仍须保留。

## 与 v0.18.0 迁移的关系

[PR #19](https://github.com/codeasier/dsh-TUI/pull/19) 的 `7c99f26c51f5a3bf58bb3eb64142713744615399` 仅作为实现来源；本分支直接从 v0.19.0 建立，没有 PR #19 的合入依赖，也不沿用它尚未执行的 CI 结论。重放其单个汇总提交后，逐项处理冲突和自动合并的语义差异。

- 上游 `/update` 的宿主引擎、全局 launcher 和 profile 三层对齐、两种启动入口校验、失败隔离与恢复均保留；只叠加已定制的 stdin 交接保护。
- 0.2.2-rc.1 宿主契约、lockfile、patch/host replica 快照及固定源码 CI lane 沿用上游，不回退为 rc.5。
- 保留上游持久模型选择、session host unload、held-input 快照、tool scope、通道失败提示和输入 composition/focus 行为。
- 平滑揭示仍按根与会话代次隔离，已完成行跨重挂载不重播；工具卡按定制即时显示有限预览，展开全文不逐行动画。

- 官方列表发现只适用于没有自定义端点、协议或连接头的 catalog 路由（包括继承配置）。初始发现连接覆盖时，在读取凭据前跳过；等待凭据或目录期间若配置变化，则在请求前再次核对，不向固定官方端点转发凭据，也不改写派生路由。

## 已知存储边界

OpenCode 使用 SQLite 只读事务保持主库/WAL 会话数据只读与一致性，但 SQLite 可能创建或更新源 `-shm`；浏览、计数与 dry-run 同样适用。严格源目录零写未实现，也未验收。不会用无法证明一致性的活动库临时复制替换现有读取。详见[迁移边界](migrate.md#opencode-支持边界)。

## 自动验收

常规 UT/build 按要求交给仓库 CI，不在本地代跑。当前 fork Actions 暂停且启用授权尚未完成，因此下面是待执行验收方案，不是通过记录。

使用 Node 24 和 package.json 声明的 pnpm。初始化子模块后，由仓库现有 CI 完成一次编译并向各组复用同一份产物。不要把只有文本合并或语法检查当作构建通过。

```sh
git submodule update --init --recursive
pnpm install --frozen-lockfile --ignore-scripts
pnpm compile
pnpm verify:build
pnpm verify:package
pnpm smoke
node scripts/run-ci-group.mjs render-scroll
node scripts/run-ci-group.mjs input-terminal
node scripts/run-ci-group.mjs session-workspace
node scripts/run-ci-group.mjs channel-ui
```

以最终提交的 `ci-gate` 和各分组结果为准，另检查 `alpha-compat` 的固定 0.2.2-rc.1 源码契约。保留上游 observation jobs 的结果及其非阻塞性质，不把未运行或 skipped 写成通过。新增回归登记在现有 runner，覆盖安装所有权/回滚/无 corepack、ag-search 桩请求、provider/OAuth、OpenCode 合成 SQLite/WAL、jobs 缓存、IME、悬挂换行、Launchpad 与整块复制。ag-search 必须在 npm tarball 中；本地安装校验同时检查 `lib` 与 `presets`。

## 真实终端验收清单

以下是待执行的方法，不是本文件宣称已完成的设备结果。使用明确授权的测试 profile 和合成会话；不要覆盖生产 profile、读取私人历史或发送收费请求来完成自动回归。

1. **环境**：记录待验收提交、Node/DSH/TUI 版本、OS、终端与是否通过 SSH/tmux；确认实际加载的包与待验收提交一致。分别使用 inline/fullscreen、窄屏和双栏宽屏。
2. **输入**：在 Launchpad 和 Chat 编辑无空格中文、标点、emoji/组合字符；检查跳词、删词、选区替换、图片 chip 原子删除。Launchpad 换行在原处增高，超过 6 行随光标窗口化；同批输入、粘贴和提交不丢字、不重复图片。进入/离开模型设置与引导后草稿保留。
3. **IME 与终端交接**：输入框右缘中文合成与提交后无残留黑带；普通移动不擦除 preedit。检查 `/restart`、正常退出和异常收尾后 raw mode、光标、底色、鼠标及同步输出恢复；不把终端回执插入草稿。
4. **转录与复制**：长代码、嵌套列表、表格、宽字符、硬换行与软换行分别局部拖选；悬挂缩进与边框不混入复制。代码/表格按钮复制原文，含缩进、空行和行尾空白；流式时复制当前内容，窄列与 inline 不露出不可用按钮。双栏复制不跨 pane，resize 后无陈旧选区。
5. **历史与 jobs**：长历史滚动、窗口缩放、`Ctrl+O`、工具展开/收起、侧栏伸缩及并发 job 标题变化不丢转录、不复用旧行高。只有有持久 hand-off 证据的工作才显示为后台任务。
6. **生命周期**：在测试插件上启用、禁用、卸载，确认授权随生命周期撤销；卸载宿主 listener 后会话结束，未送达输入保留但不自动重发，重新挂载后显式恢复。
7. **provider 与导入**：首次配置 provider 的 0/1/多个模型路径保持明确；catalog 新模型不自动启用。用桩测试确认 `/fast` 下一请求生效、重启不持久化、未支持协议不受影响。OpenCode 用合成 DB/WAL 测只读导入、压缩/revert 和重复导入，不访问私人会话。
8. **升级**：在隔离 profile 上验证 `/update` 的三层对齐、host skip 原因保留、两种入口与失败恢复；升级、重启后 held inputs 不串会话、不重复投递。
9. **安装**：在隔离临时 HOME/profile 验证缺 corepack、所有权冲突、profile 锁、失败回滚以及 `lib` 或 `presets` 单独不一致。真实安装需另行授权，生成并读回新版 package ID，不能复用旧机器记录。

验收记录应列出提交、场景、通过/失败/未执行、证据和剩余问题。此迁移不打 tag、不发布、不部署；实际设备验收未执行前，不宣称上线完成。
