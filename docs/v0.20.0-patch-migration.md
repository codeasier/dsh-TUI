### 有意保留的定制差异

- Launchpad 换行继续原地增高，而非上游的换行进入 Chat；保留同批输入、图片 chip 原子删除、焦点/composition 与挂起后就绪再接收输入的保护。
- 工具卡显示有限预览，点击或 `Ctrl+O` 后完整直出，不逐行动画；`smoothStreaming` 仍作用于回复与展开的思考，历史/回放直接显示。展开工具卡继续使用选定背景；显式 `none` 不加底色。
- 保留中性灰画布、用户 prompt/输入框粗黄色条带、低对比普通工具摘要与悬挂缩进；原文复制按钮不取代上游软折行和分栏选区。
- 保留原安装/升级安全边界与 `/update` stdin 交接保护，不用旧版 adapter、依赖锁或宿主快照覆盖 v0.20.0。

## 冲突整合要点

- 局部压缩的持久 `compactPreview` 优先于旧格式的精确包裹解码；新版 partial checkpoint 展开时保留完整原文，不把预览截取或旧格式解码套到展开正文上。
- Edit/Write 卡片结合上游 git-hunk diff、定制最多八行的折叠 diff 预览和左侧边线几何；不能为套用旧预览而恢复旧版全文 diff 或挤占正文宽度。
- 同时保留 `inline-shrink-to-fit` 与 `reanchor-growth` 门禁，回归夹具的输出序列和几何预期随整合调整。这些回归本轮未执行，修改断言不代表验收通过。

## 已知存储边界

OpenCode 的 SQLite 只读事务保证主库/WAL 会话数据不被导入器改写并保持一致快照，但 SQLite 可能创建或更新源目录中的协调 sidecar `-shm`；浏览、计数和 dry-run 同样适用。**严格源目录零写未实现、未验收。** 不以未经一致性证明的活动库临时复制替代现有读取。详见[OpenCode 支持边界](migrate.md#opencode-支持边界)。

1. **输入/渲染**：分别在 inline/fullscreen、窄屏/双栏下，编辑中文、标点、emoji/组合字符，换行超过六行并移动光标，粘贴后提交，删除图片 chip；调整窗口、开关侧栏和 `Ctrl+O`。确认草稿无丢失/重复、IME 不留黑带、底栏与短帧贴底、长帧收缩无空白带。
2. **思考/工具/复制**：在合成流中依次切换空思考、文本、纯计数、完成、再次流式、展开/收起和卸载，检查 hook 错误及 spinner 清理；工具短预览/即时展开保持定制。拖选软/硬换行、列表、代码和表格，按钮复制保留原文空行/缩进/行尾空白，跨 pane 不串选。unified diff 核对有/无真实偏移、多 hunk 与大改动回退。
3. **会话/宿主**：用合成记录核对 partial checkpoint 的实时/回放/`/tree`、jobs 持久描述与后台 hand-off、持久模型/effort、插件撤销及宿主卸载后的 held input。rc.2 试 `/team on`、`/team off` 与 detached 子会话归属；旧宿主单独核对降级，不共享 rc.2 写过的库。

5. **通知/交接**：用测试事件覆盖四种等待/完成通知、失焦/off、会话切换、关闭/迟到响应、账号卡片实际写屏及语言更新；Windows 上单独验收 `jumpBack` 成功与无法核实/目标已消失的安全降级。正常退出、`/restart` 和异常收尾后检查 raw mode、光标、底色、鼠标与同步输出恢复。
6. **安装/升级（另行授权后）**：隔离 HOME/profile，按 `scripts/local-install.sh` 的说明检查无 corepack、所有权冲突、profile 锁、失败回滚及 `lib`/`presets` 各自不一致；该脚本会编译，不在本轮运行。另测 `/update` 三层对齐、两种入口、host skip 原因和失败恢复；记录新版 package ID 并读回真实加载路径，确认 held input 不串会话、不重发。
