## 分支里有什么？

父提交是官方 [v0.20.2 标签](https://github.com/ccch1mneyyy/dsh-TUI/releases/tag/v0.20.2) 解引用后的 `55b33aea793f34e3cab48a5579f3e7595031e72e`，不是持续更新的上游分支。已合入定制的正式来源是 [#25](https://github.com/codeasier/dsh-TUI/pull/25) 的 `cc9926e67affe9cdf29f075c0e920543d7f8348d`。本次重放 [#26](https://github.com/codeasier/dsh-TUI/pull/26) 已整合的补丁，即从官方 v0.20.1 `9f3928c80da3c384eeae15a13159dcddb2475f54` 到 `57dbcf0b7d053a24edf547179f18df57f126ee8b` 的差异。它覆盖正式补丁的全部 259 个路径，并增加两份历史迁移文档与提及补全回归适配。无需先合 #26，历史记录不作为本提交的验收证据。

包版本保持 **0.20.2**，首要宿主是 **DSH 0.2.2-rc.5**，保留 rc.4、rc.3 兼容。锁文件、peer/dev 范围、patch-surface 和 host-replica 快照沿用上游。CI 的 rc.5 宿主固定在 `9c2670d3bce5275e0d1610272958121af87787bb`；验证使用 Node 24 系列（至少 24.9）及 pnpm 11.21.0。维护分支不等于标签、npm 版本、安装包或独立更新通道。内置 `/update` 指向官方包，不会更新为本 fork 的候选版本。

## 重点组合场景

| 场景 | 这版怎么验 |
| --- | --- |
| 全屏跨页选区与原文复制 | 向前跨多页拖选，再反向滚回，覆盖两个端点都离屏的情形。在分栏中验证中日韩宽字符软换行与原始硬换行，逐字节比较剪贴板。代码/表格按钮经 OSC 52 复制原文，局部拖选仍只复制所选内容。 |
| 交付卡与转录 | 对同一次 `present` 分别看实时与回放：应显示文件行、大小、解析路径、描述与文件操作菜单，而不是普通行内摘要。切换 none/subtle/strong、极简模式与图标设置，覆盖窄栏和超长路径；普通工具仍按本 fork 的摘要/预览/展开规则显示。 |
| 网页搜索与模型目录 | rc.5 选“自动”后仅清除用户层覆盖；base 固定 provider 时不可选“自动”。以假值测试 Messages/Search API 共用或分别使用凭据引用。继承代理端点或 headers 时不得误探供应商默认公网端点；启用模型、原始模型对象及 overrides 保持不变。ag-search 仍为可选配置，日志不输出凭据值。 |
| 重启与安装 | 在 POSIX 验证原地 execve 的 PID、TTY 及待刷写输出，再分别测监督回退和 Windows 引擎解析；监督进程须解绑 stdin，不能破坏子进程 raw 模式。在一次性 profile 核对 tarball 归属、锁竞争、无 corepack 的版本选择、摘要校验以及失败回滚的非零退出码。 |
| 既有定制 | 复核中文输入法配合提及补全、Launchpad 焦点、思考折叠的 hook 顺序、用户提示换行、OpenCode 导入、OAuth /fast、任务进度/标题/耗时缓存，以及 stderr 分级和销毁后的静默。使用合成会话与离线 provider stub。 |

## 尚待执行

源码与回归注册核对不等于编译、实际屏幕或安装包验收。本次未安装依赖、运行完整 CI、打包、安装/升级 profile，也未做真实终端及 Windows/macOS 验收。上游绿灯、旧包和跳过项均不代表本候选通过。维持 fork Actions 的暂停状态。

获准在对应 runner 验证时，固定候选 SHA，初始化子模块并冻结依赖；编译一次后复用产物：

```sh
git submodule update --init --recursive
pnpm install --frozen-lockfile --ignore-scripts
pnpm compile
pnpm verify:build
pnpm verify:package
pnpm smoke
for group in render-scroll input-terminal session-workspace channel-ui; do
  node scripts/run-ci-group.mjs "$group" || exit 1
done
pnpm verify:local-install-ownership
pnpm verify:local-install-rollback
```

记录提交、宿主版本、系统/终端、命令和结果。留存 inline、fullscreen 及窄宽度真实输出。安装验收应记录候选 tarball 的摘要，并在隔离 profile 检查 lib、presets 与 guide；不要拿 registry 同号包代替。旧宿主的会话库需隔离；OpenCode 只读查询也可能更新 SQLite 的 `-shm`，请使用一次性 fixture。本次不使用生产 profile，也不通过发布来验证。
