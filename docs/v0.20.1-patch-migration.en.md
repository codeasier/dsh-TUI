### Cross-feature regression adaptations

- The stderr disposal fixtures use synthetic `Error:` lines for the unterminated child tail, queued pre-disposal notice, and late post-disposal push. Otherwise informational-line suppression would invalidate the active-reporter negative control and leave the cancellation assertion with no timer to cancel. Keep the real subprocess tail, ended Channel, and repeated-disposal checks.
- The mention-provider regression checks the composer controller's exact `Camera ` draft after Enter instead of assuming a prompt row starts with `❯`; the custom yellow rail remains. Keep the other upstream rendering, asynchronous selection, and batched-input assertions.
- Keep both `verify-claude-sdk-status` and `verify-ime-cursor-repair`, plus every mention-provider, host-migration, and existing customization regression registration. Do not weaken gates.
- Migration docs retain both host-resolution failure troubleshooting and OpenCode session-row counting. Bundled guide copies stay byte-identical.

## Verification status

This pass is static only: provenance and file ownership, conflict markers/whitespace, JS/TS/TSX syntax, shell syntax, JSON, fidelity of upstream-only and customization-only files, version/dependency contracts, regression registrations, and guide mirrors. **Syntax parsing is not TypeScript type checking or runtime acceptance.** The migration PR records exact commands/results.

**Not run:** dependency installation, TypeScript compilation, `pnpm build` / `verify:build` / `verify:package` / `smoke`, behavior regressions/full CI, real terminals, actual installation/upgrades, Windows or device acceptance. Routine UT/build remains with existing CI; this pass does not enable or rerun paused Actions. Unrun, absent, and skipped checks are not passes. Migration completion does not establish merge or release readiness.

When execution is authorized later, use Node 24 (at least 24.9 for the host) and the package's pinned pnpm; compile once and reuse artifacts:

```sh
git submodule update --init --recursive
pnpm install --frozen-lockfile --ignore-scripts
pnpm compile
pnpm verify:build
pnpm verify:package
pnpm smoke
node scripts/run-ci-group.mjs render-scroll
node scripts/run-ci-group.mjs input-terminal
node scripts/run-ci-group.mjs session-workspace
node scripts/run-ci-group.mjs channel-ui
```

Focus on `verify-mention-providers.tsx`, `verify-child-stderr.tsx`, `verify-claude-sdk-status.tsx`, `verify-cli-subcommands.mjs`, `verify-backend-host.ts`, the three OpenCode regressions, jobs/cache, thinking hooks, catalog, and installer rollback.
